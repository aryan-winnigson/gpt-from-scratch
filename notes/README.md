# Notes

One file per stage, written **after** the tests go green, **in my own words**, **without
re-reading the stage README while writing**.

This is not documentation. It's the test of whether I actually learned the thing. The
rule from the Feynman method: if I can't explain it plainly on a blank page, I don't
understand it yet — and the specific sentence where I get vague is exactly the thing to
go back and re-derive.

Template:

```markdown
# Stage NN — <title>

## In one paragraph
<what this stage was about, as if explaining to a competent programmer who knows no ML>

## The thing that confused me
<and how it resolved — these are the entries I'll reread in six months>

## The thing I got wrong first
<the bug, the symptom, the fix. Be specific about the symptom.>

## Answers to the stage questions
<every question from the README, answered from memory>

## If I had to rebuild this from scratch tomorrow
<the 5-line sketch I'd start from>
```
